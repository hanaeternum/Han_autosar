### 上传流程踩坑（可复用）
1. 网盘上传三步：`file_upload` 拿签名 URL+headers → `curl -X PUT -T 文件` 推流 → `file_upload_complete` 落库。缺最后一步网盘里不会出现文件。
2. MCP 接口有**每 5 秒限流**，一批并发 5~6 个通常会有 1 个报 `406450 调用过于频繁`，重试即可；`dir_create` 更易被限。
3. `file_upload` 返回的 `x-cos-security-token` 很长（~900 字符）且会在同批多个文件间**复用**。批量上传时把这些 token 存进本地 shell 变量文件（如 `T1=...`）再 `source`，能显著省去重复粘贴。
4. Windows 的 `find` 会被系统自带 find.exe 劫持，列文件改用 Python 或 Glob。
